# PiperTTS

GUI tool for the well-known piper text to speech software...

How to configure? 

Do yourself a favor and visit my Kokoro TTS repository.

Same installation procedure.

But piper needs internet to download the voices, so, use the voices dropdown to trigger downloads.

Choose a voice -> Paste text -> Python auto-downloads the voices once and for all -> Generate sample audio -> Enjoy! 🚀

Install python 3.12 -> Create a venv -> Install the requirements like pygame -> Launch my GUI just like I explained for Kokoro.
